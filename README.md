Resumo
------
Patagônia é uma aplicação de geolocalização de localidades no Brasil, desenvolvido com Spring Boot 4, Bootstrap 5.3, Thymeleaf 3 e Javascript. Foi desenvolvido com JDK 21 e OpenStreetMap (OSM) com acesso ao Projeto Babilônia para informações de localidades do Brasil.

**Principais funcionalidades**

- Mapa padrão OpenStreetMap;
- Uso da API Leafflet em Javascript para integração do OSM;
- Incorpora arquivo MWW.COF da NOAA para geomagnetismo terrestre;
- Cálculo de azimutes verdadeiro e magnético;
- Determinação de distância entre pontos no mapa.
